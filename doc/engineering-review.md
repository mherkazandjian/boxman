# Boxman engineering review

Comprehensive software/engineering review of boxman @ `a050b3e` (main, post-#82): ~27k LOC src (76 py files), ~21k LOC tests (58 files). Four parallel deep-dives covered: core/config, libvirt provider, docker-compose/virtualbox providers + runtime + netlab, and cross-cutting packaging/tests/docs. All line refs verified against the working tree; the top two severity claims spot-checked by hand.

## Executive summary

Boxman's feature surface is broad (libvirt + docker-compose + virtualbox stub, netlab/containerlab, snapshots, OCI images, PXE) and its happy paths are well-tested (1673 unit tests green). The systemic problems are not missing features but:

1. **Failure semantics**: many failure paths exit 0, parallel child results are lost, and `--vms` scoping is silently ignored by destructive verbs — boxman cannot yet be trusted in automation.
2. **One god object**: `manager.py` is 6806 lines / ~130 methods / ~25 responsibilities, held together by a `@staticmethod`-with-`cls` anti-pattern and ~29 hand-built name strings.
3. **Four virsh invocation styles, three config merges, three docker-exec wraps**: the same cross-cutting concern is re-implemented with subtle divergence each time; several copies are buggy (drop URI, break on spaced paths, ignore sudo config).
4. **Dead/broken scaffolding**: `export`/`import` subcommands wired to broken legacy functions, dead modules that are themselves broken, ~300+ lines of unreachable code, stale docs.
5. **Packaging/hygiene**: abandoned contradictory `requirements.txt`, non-reproducible wheels leaking gitignored files (incl. `containers/docker/.env`), no CI, `.github` gitignored, 272 ruff violations.

## P0 — correctness: data loss / false success (fix first)

1. **`src/boxman/providers/libvirt/disk_cleanup.py:72` — prefix glob deletes other VMs' disks.** `glob(f'{vm_name}*')` sweeps leftovers; with VMs `web`/`web2` in one cluster, destroying `web` deletes `web2.qcow2` + its snapshot overlays. *Fix:* exact-name enumeration (boot disk, `{vm}_{disk}.qcow2`, `{vm}_snapshot_*`, `^{vm}\..+` overlays) or derive from `domblklist`/`snapshot-list` before undefine. Add `web`/`web2` regression test.
2. **`--vms` silently ignored by `control`, `storage`, `snapshot list`, `snapshot log`.** `process_vm_list` (`manager.py:5778-5789`) and `_storage_targets` (`manager.py:5556-5564`, verified) accept but never read `cli_args`; the correct `_select_vm_targets` (`manager.py:5158-5211`) is only wired into snapshot take/restore/delete. `boxman control save --vms node01` saves *every* VM. *Fix:* route all six verbs through `_select_vm_targets`; delete `process_vm_list`/`_storage_targets`.
3. **Failure paths exit 0.** `provision`/`up`/`snapshot_take`/`snapshot_restore` log-and-`return` on failure (`manager.py:4256-4302, 4432-4456, 5281-5284, 5363-5387`) → process exit 0. *Fix:* raise `ProvisionError`/`ConfigError` (or `SystemExit(1)`) from these paths.
4. **Parallel child failures swallowed; one worker gap prints "all VMs restored successfully".** 17 `Process()` sites; only 2 check `exitcode`. `_restore` (`manager.py:5395-5397`) doesn't catch exceptions → child dies before `queue.put` → `q.empty()` drain (`5415`) never sees it. `get_connect_info` blocking `get()` (`3556`) can deadlock. *Fix:* one `_run_parallel(tasks)` helper: join, `get(timeout=…)` per process, missing result = failure; wrap worker bodies in try/except that always `queue.put`s.
5. **cloud-init guest-agent calls drop `-c {uri}`** — 6 sites in `src/boxman/providers/libvirt/cloudinit.py` (607, 648, 687, 715, 734, 779) run raw `execute_shell(f"virsh qemu-agent-command …")`, ignoring configured URI/virsh_cmd → non-default-URI template creation polls the wrong daemon. *Fix:* one `_agent_command()` helper going through `self.virsh.execute(...)`.
6. **Shell-quoting (issue #83) full map.** Root: `commands.py:build_command` does `" ".join(parts)` unquoted. Per-site hand-quoting across snapshot.py/net.py/disk.py/storage.py/cloudinit.py/import_image.py (breaks on spaces/quotes/metachars); unescaped XML f-strings in `disk.py:143-147`, `cdrom.py:85-88,212-217`, `shared_folder.py:317-321`, `network.xml.j2` (only DHCP host attrs escaped). Proof the fix is known: `direct_vm.py`/`iso_boot_vm.py` use `shlex.quote`; `oci_pull/push` use argv-list subprocess. *Fix:* quote every value centrally in `build_command` with `shlex.quote`, delete per-site manual quoting; long-term argv-list execution.
7. **`boxman ps` ignores `boxman.yml` and runtime** (`app.py:392-402`, `manager.py:6068-6075`): no app-config merge, no runtime injection → queries host libvirt instead of the docker-runtime container. *Fix:* single manager `_virsh()` helper (also kills the 5× copy-pasted "resolve provider config for a one-off virsh query" block).

## P1 — correctness: operational traps

8. **Provider-config merge implemented 3× with divergent semantics.** `_merge_provider_configs` (`manager.py:470-502`, sudo-list aware) vs `app.py:628-640` plain `update()` vs `LibVirtSession.provider_config` third overlay (`session.py:54-118`). The session that runs the commands is the one path that skips the documented merge. *Fix:* one merge function used everywhere; drop the session-side overlay.
9. **Runtime wrap duplicated 3×, half-wired.** `runtime/docker_compose.py:106-109` == `commands.py:245-266` (byte-identical) == `template_manager.py:241-246`; `update_provider_config_with_runtime()` applied in only 5 of ~10 verb flows (missing from all snapshot/control verbs); missing injection silently falls back to container `boxman-libvirt-default`. *Fix:* pass the runtime *instance* to the session/command base and delegate to `runtime.wrap_command()`; missing `runtime_container` under docker runtime = hard error.
10. **App-level provider settings dropped for non-libvirt providers** (`app.py:617-642` guards `_ptype == 'libvirt'`): `boxman.yml` `docker-compose:`/`virtualbox:` keys silently ignored. *Fix:* same merge path for every provider type.
11. **`primary_provider_type` ("first `provider:` key") feeds libvirt pre-checks the wrong config** in mixed projects (`manager.py:1610, 4121, 4150, 4185`). Shipped boxes list libvirt first, masking it. *Fix:* resolve `config['provider']['libvirt']` explicitly; skip when no libvirt clusters.
12. **`get_latest_snapshot` raises instead of returning None** (`snapshot.py:450`, no `warn=True`) → `snapshot restore` on a never-snapshotted VM tracebacks; the graceful paths at `session.py:1290-1294`/`manager.py:5362-5366` are unreachable.
13. **Network existence check is a substring grep** (`net.py:785,791`, no `-x`, unquoted) — `prod` matches `prod-backup`; destroy then fails mid-operation. Fix: `net-list --all --name` + exact match via existing `_listed_networks()`.
14. **Hand-rolled NAT iptables duplicate libvirtd's own rules** (`net.py:1140-1214` add, `1022-1093` remove-by-current-route → leaks stale rules; hardcoded `sudo` ignores `use_sudo: false`; offline hosts break `ip route get 8.8.8.8`). *Fix:* drop boxman's NAT rules, let libvirt own NAT; keep only the route-isolation rules; route sudo through `_should_use_sudo_for_command`.
15. **Runtime-scope conflict filter inverted for local runtime** (`net.py:636`): local runtime conflict-checks docker-runtime projects (different libvirt instance) → false conflicts.
16. **`destroy` confirmation prompt crashes on EOF** (`manager.py:4926-4930`, no `EOFError` guard; three sibling prompts have it).
17. **Missing `conf.yml` → raw `FileNotFoundError` traceback** (verified empirically); translate to `ConfigError`. Same class: user-facing `ValueError`/`KeyError`/`RuntimeError` in `task_runner.py:217,299`, `jinja_env.py:28-38`, `_select_vm_targets`, `create_runtime` — standardize on the existing `exceptions.py` hierarchy.
18. **Storage compact can run while QEMU holds the disk** (`storage.py:175-192` gates on "not running"; paused/in-shutdown slips through → `qemu-img convert && mv` on a live image). Gate on `DestroyVM.is_vm_shut_off` semantics.
19. **Containerlab `ensure_up` lab-prefix collision** (`containerlab.py:236-241`): docker `name=` filter is substring → labs `foo`/`foo-bar` interfere. Fix: `--filter label=containerlab=<lab>`.
20. **Relative netlab workdir breaks containerlab startup-config paths** (`manager.py:442-449` expanduser-only; containerlab resolves relative to topology dir). Fix: `Path(workdir).resolve()`.
21. **Docker-compose runtime rewrites a user-supplied compose file in place** (`runtime/docker_compose.py:135-179, 529-556`): pyyaml re-dump destroys comments; drops a `.env` next to it. Fix: mutate only the `.boxman` copy; for user files use a `-f` override file.
22. **Shared bridges: no name validation/quoting, no MTU knob, IPv4-only accept rule** (`shared_bridges.py:31,129-135`): unquoted f-strings into sudo'd shell; no IFNAMSIZ 15-char check; bridge MTU 1500 vs containerlab veth default 9500 = silent jumbo blackhole. Fix: validate `^[a-zA-Z0-9_.-]{1,15}$`, `shlex.quote`, optional `mtu:`, document/extend to ip6tables.
23. **vm_differ skips a desired disk when a stale file exists** (`vm_differ.py:348`): neither "new" nor "resize" → silently never attached, update reports success.
24. **Cache↔libvirt divergence + no atomicity.** `deprovision` unregisters even when unchecked teardown children failed; `remove_network` never updates cache; `config_cache.py` read-modify-write without tmp+`os.replace`/lock; corrupt `projects.json` crashes every command; `register_project` annotated `-> bool` returns None.
25. **Monolithic force-undefine version-fragile** (`destroy_vm.py:233`): all flags one string, `--delete-storage-volume-snapshots` needs recent libvirt, no fallback to plain `undefine` → VM can become unkillable.
26. **CDROM target/bus mismatch** (`cdrom.py:215,246-249`): `sdX` target + hardcoded `bus='ide'`. **Template force-recreate races** (`cloudinit.py:908-914`): no shutdown-wait before undefine. **`_verify_dhcp_on_network()` result ignored** (`cloudinit.py:922`) → multi-minute agent timeout instead of fast fail.
27. **Snapshot restore doesn't ensure shared bridges** (`manager.py:5318-5330` vs every other bring-up path) → cryptic macvlan "parent interface does not exist" after host reboot.
28. **VirtualBox provider registered but every op dies with raw `NotImplementedError`** (~40 stubs). Either catch and exit 2 with "Phase 1, non-functional", or unregister until Phase 2.

## P2 — consolidation (structural)

29. **Split the god object.** `manager.py` 6806 lines, ~130 methods. Clean contiguous boundaries already exist: `config/loader.py` (504-787, 1956-1996), `naming.py` (the ~29 inline `bprj__…__bprj` sites), `workspace.py` (789-1374, 3674-3763), `images.py`/`templates.py` (1459-2382), `networks.py` (2542-3124), `vms.py` (3126-3562, 6284-6805), `ssh.py` (3645-4096), `snapshots.py`/`storage.py` (5005-5848), `flows.py` (4219-5003). Slim core keeps config/sessions/runtime/cache/netlab (35-468).
30. **Kill the `@staticmethod`-with-`cls` anti-pattern** (~40 flow methods, e.g. `manager.py:4219-4220`): only work via `args.func(manager, args)`; app.py compares function identity 10+ times. Make them instance methods; dispatch via name map / `set_defaults(handler=…)`.
31. **One virsh path.** Four styles today: `VirshCommand.execute`, raw `execute_shell(f"virsh …")` (cloudinit, drops URI), raw `run(f"virsh -c …")` (import_image), dead manual building (template_manager). Consolidate on `VirshCommand` (composition over inheritance — `Network`/`DiskManager`/`CDROMManager`/`SharedFolderManager` currently subclass it as an execution mixin).
32. **Shared parsers with golden fixtures.** `domblklist`/`domiflist` parsing exists ≥7× (session/net/clone_vm/snapshot/vm_differ/cdrom); only `manager.py:3393` survives spaced paths. One `parse_domblklist/domiflist` + per-libvirt-version golden-output tests (current mocks can't catch parse regressions).
33. **Deduplicate provider-internal helpers** (verbatim or near-verbatim copies): shutdown-and-wait ×5, snapshot-chain listing ×4, virt-install building ×3, docker-exec wrap ×3, CPU/mem max-clamping ×2 (virsh_edit vs session, already divergent), device listing ×2 each (cdrom/shared_folder vs vm_differ), disk-path naming ×4, `${env:VAR}` substitution ×2, wait-for-IP loop ×3 (helper exists at `manager.py:2853-2878` but provision/up/update re-roll it), clone-with-retry worker ×2 (incl. 18-line comment), ISO download ×2 (`manager.py:2062-2088` vs `utils/http_download.py`, already drifted on `-f`).
34. **Session config-surface duplication across providers**: `virtualbox/session.py:41-124` ≈ `libvirt/session.py:41-102`; `DockerComposeSession.update_provider_config` has different (last-write-wins) semantics under the same protocol method. Extract one mixin. Same for the two compose-name sanitizers.
35. **CLI parser**: shared parent parsers for the ~15 identical `--vms` blocks; derive provider choices from `PROVIDERS` (drifted already); `--runtime` choices missing `docker-compose`; remove parsed-but-unconsumed `--live/--no-live` (help texts are also swapped).

## P2 — cleanup: dead code & docs

36. **Delete broken user-facing commands**: `export`/`import` (`app.py:181-224`, `cli_parser.py:991-1025`) — wired to a removed VirtualBox-era Session API, traceback today. Removing them also breaks the `cli_parser`↔`app` circular import.
37. **Delete dead modules/functions**: `template_manager.py` (self-admitted dead, calls wrong-arity `build_seed_iso`, nonexistent `ci.cleanup()`) + its test file; `app.py:51-224` (~150 lines legacy snapshot/machine helpers); `manager.py:3221-3245, 3447-3526` (zero-caller VM methods); `net.py:752-774` (`define_and_start` calls nonexistent methods); `session.py:482-514` (`destroy_network/undefine_network` — dead and dangerous); `virsh_edit.py:370-433`; `abstract/hosts_specs.py` (debug `print` in `__init__`); `import_image.py:29-37` empty class; 4 of 5 conftest fixtures unused (~140 lines).
38. **Systematic dead error branches**: `self.execute(...)` without `warn=True` raises, so following `if not result.ok:` is unreachable in disk.py/cdrom.py/virsh_edit.py/clone_vm.py (~12 sites) — pass `warn=True` or delete the branch. Inconsistent error contracts overall (bool vs RuntimeError vs ValueError vs ProvisionError from `-> bool` methods).
39. **Packaging fixes**: delete `requirements.txt` (installs `pyaml`/`typer`/`requests`/`gdown`/`multiprocess` — none imported; omits Jinja2/passlib) + fix `README.md:31`; stop force-including gitignored `containers/docker/.env` and `boxes/**/*.rendered.yml` into the wheel (leaks demo passwords; ships a deleted box's leftover rendered file); exclude via git-tracked list; placeholder `metadata.py` (`John Smith`, `boxman.example.com`) + wrong pyproject `homepage`.
40. **CI**: `.github` is in `.gitignore` (over-ignore); no workflows. Un-ignore, add minimal workflow (`ruff check` + default pytest tier); `ruff check --fix` clears 128 of 272 violations mechanically.
41. **Docs/Makefile drift**: AGENTS.md lists 7 subcommands vs ~23 real; `test-integration` target hardcodes the old 2-test file and its documented lifecycle recipe can't run; `Makefile` has zero `.PHONY` + dead `docs`/`nothing:` targets (and a `/etc/shadow` bind-mount in a doc build); `data/templates/conf.yml` == `conf.virtualbox.yml` byte-identical v1 leftovers; `data/assets/` fully dead; 58 references to a private `/home/mher/.claude/plans/…` path in shipped docstrings; `doc/pxe-support-plan.md` describes implemented work as future; `tests/README.md` empty.
42. **Test consolidation**: `test_update.py` (45) and `test_docker_compose_provider.py` (147) lack `pytestmark = unit` → `-m unit` silently skips 192 tests; `_make_manager` redefined 5×, `MINIMAL_DOMAIN_XML` copy-pasted — move to conftest (synergy with #37 fixture cleanup); pin the arbitrary-order `conf*.yml` smoke test.
